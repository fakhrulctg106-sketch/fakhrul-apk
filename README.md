# Fakhrul APK Store — Version 2

This is the branded Version 2 of the APK Store prototype.

## Preview
Open `index.html`.

## Admin prototype
Open `admin.html` to add app records. This prototype saves records in browser localStorage.

## Important before publishing
1. Add a real backend/database and secure admin authentication.
2. Implement server-side APK uploads rather than accepting arbitrary URLs.
3. Add privacy policy, terms, contact/DMCA pages.
4. Only distribute APKs you own or are authorized to distribute.
5. Add malware scanning/checksums and file validation.
6. Add an approved advertising network after the site meets its policies.
